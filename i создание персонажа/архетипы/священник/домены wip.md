# Домены WIP

Шаблон домена: 8 заклинаний, по PR — 2 / 1 / 2 / 1 / 1 / 1 (последнее — кульминация на PR 6–7). Допустим сдвиг на ±1 соседнюю ступень, но на PR 1–5 не должно быть пустых ступеней.  
*Запас* — заклинания, убранные из домена, на случай замены.  
Доменные заклинания не имеют требований, кроме PR: священник получает их, даже если не знает предшествующих заклинаний, не имеет нужных характеристик или Forbidden Lore. Например, Обет доступен без Порабощения. Кроме того, каждый священник с PR 3+ знает заклинание [Spirit Guardians / Духи-Хранители](/V%20Магия/5%20Заклинания/3%20Малые%20дисциплины/13%20Теургия#spirit-guardians-new), независимо от доменов.
