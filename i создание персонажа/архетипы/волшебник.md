## Трейты
#### Arcane Spellcasting / Арканное Колдовство
**Запас маны:** 2xI.b + 2xPR  
Арканный заклинатель использует I для тестов магии.  
В начале дня арканный заклинатель может подготовить до I.b + PR заклинаний из своей книги заклинаний и использовать их множество раз в течение дня.  
Арканный заклинатель не может использовать заклинания без [[Пути Силы|V Магия/2 Пути Силы]] и со старта получает доступ к Пути силы Инкантации. Также он может открыть следующие Пути силы: Телесная Конверсия, Жертва, Мистический Танцор, Тайные Символы, Личный Фокус, Фамильяр. При использовании Путей Тайные Символы, Личный Фокус и Фамильяр арканный заклинатель обязан комбинировать их с одним из путей силы Инкантации, Телесная Конверсия, Жертва или Мистический Танцор.  
Арканный заклинатель может знать любое количество заклинаний и изучает их за половину стоимости в XP. Однако для изучения заклинания он должен найти учителя, книгу заклинаний другого волшебника или свиток с желаемым заклинанием, после чего записать его в собственную книгу заклинаний. Свитки при успешном переписывании заклинания считаются использованными. Изучение заклинания и запись в книгу требует исследования через Spellcraft с банком успехов равным PR × 5 и модификатором сложности +(15 - PR × 5), где PR это PR, необходимый для изучения заклинания.   
##### Книга заклинаний (R2)
Книга заклинаний содержит 100 страниц. Каждое заклинание занимает 1 страницу за каждый требуемый для изучения PR.  
При утрате книги заклинаний он может без траты опыта записать в новую книгу те заклинания, которые уже знал. Арканный заклинатель может использовать собственную память как источник для заклинаний, подготовленных на данный момент. Для восстановления неподготовленных заклинаний вновь потребуется внешний источник, из которого можно переписать заклинание.  
Арканный заклинатель может подготавливать заклинания из чужой книги заклинаний с помощью теста Spellcraft +0, но не может подготавливать заклинания, на изучение которых он не тратил опыт.
