# Недоспелкастинг

Недоспелкастеры не имеют PR и не добавляют бонус от него к тестам магии, а используют навык **{{Указано в Таланте}})** для тестов магии.  
Не провоцирует феномены и прорывы.  
Уровень прокачки навыка влияет на эPR применяемого заклинания следующим образом:  
Не прокачен — не позволяет использовать  
+0  — 1 PR  
+10 — 2 PR  
+20 — 3 PR  
+30 — 4 PR  
Mastery — 5 PR  

Заклинания стоят количество маны, равное уровню таланта, который давал это заклинание.

Недоспелкастер может поддерживать лишь одно заклинание. Поддерживание этого заклинания не увеличивает сложность теста магии для произнесения заклинания.

Для каждого класса определённый набор доступных заклинаний.

(?) Восстановление маны только на длинном отдыхе. (нет)
