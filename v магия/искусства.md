# Искусства

Искусства — магия Барда, Паладина и Следопыта. Владеющие Искусствами не имеют PR и не добавляют бонус от него к тестам магии, а используют навык, указанный в Таланте Искусства, для тестов магии.  
Не провоцирует феномены и прорывы.  
Уровень прокачки навыка влияет на эPR применяемого Искусства следующим образом:  
Не прокачен — не позволяет использовать  
+0  — 1 PR  
+10 — 2 PR  
+20 — 3 PR  
+30 — 4 PR  
Mastery — 5 PR  

Вместо маны Искусства расходуют фокус. Применение Искусства стоит количество фокуса, равное уровню таланта, который давал это Искусство.

Владеющий Искусствами может поддерживать лишь одно Искусство. Поддерживание этого Искусства не увеличивает сложность теста магии для применения Искусств.

Для каждого класса определённый набор доступных Искусств.
